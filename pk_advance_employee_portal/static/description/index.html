Configuration

  • Make sure the employee is linked with a portal user.
  • Go to employee profile --> HR Settings tab --> select the portal user.
  • Next, go to Settings --> Users & Companies --> click on Groups (developer mode activated).
  • Search or select these groups:
    • Custom Portal - My Profile Access
    • Custom Portal - Payroll Access
    • Custom Portal - Time Off Access
    • Custom Portal - Weekly Schedule Access
    • Custom Portal - Tasks Access
    • Custom Portal - Expenses Access
    • Custom Portal - Attendance Access
    • Custom Portal - Sales Access
  • Remember: only assigned group Apps/Menus will be visible to the user.
  • Add users in the order line as many as you want.
  • Now log in with the user to see the menu as below.
