# Nominas Cahosa Odoo 18

Repositorio con módulos personalizados de Nómina y Recursos Humanos para Odoo 18 desarrollados para Cahosa.

## 📦 Módulos incluidos

### Módulos de Nómina
- **kc_payroll_full**: Módulo completo de nómina
- **l10n_hn_hr_payroll**: Localización de nómina para Honduras
- **payroll_hn**: Nómina Honduras

### Módulos de Recursos Humanos
- **l10n_hn_hr**: Localización de RRHH para Honduras
- **l10n_hn_hr_contract**: Contratos de empleados
- **l10n_hn_hr_holidays**: Vacaciones y días festivos
- **l10n_hn_hr_recruitment**: Reclutamiento
- **kc_hr_extra_hours_request**: Solicitud de horas extra

### Módulos Portales
- **hr_hn_portal_expense**: Portal de gastos
- **hr_hn_viatic_portal**: Portal de viáticos
- **l10n_hn_hr_holidays_portal**: Portal de vacaciones
- **l10n_hn_loan_portal**: Portal de préstamos
- **l10n_hn_hr_salary_advance_portal**: Portal de adelanto salarial
- **pk_advance_employee_portal**: Portal de adelantos de empleados

### Otros Módulos
- **kc_biometric_connect**: Conexión biométrica
- **l10n_hn_loan**: Préstamos
- **l10n_hn_salary_advance**: Adelanto salarial
- **simplify_access_management**: Gestión simplificada de acceso

## 🚀 Instalación

1. Copia este repositorio en la carpeta de addons de Odoo:
```bash
cd /opt/odoo/addons
git clone https://github.com/luisd.beteta10/Nominas-Cahosa-Odoo-18.git
```

2. Asegúrate de que la ruta esté en el addons_path de tu configuración de Odoo

3. Actualiza la lista de aplicaciones en Odoo y instala los módulos necesarios

## 📝 Requisitos

- Odoo 18.0
- Python 3.8+
